# Fish Era

Restaurant Portal for Fish Era, built with React, Vite, Tailwind CSS v4 and lucide-react.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
npm run lint
```

- `src/pages/RestaurantPortal.jsx` — Restaurant Portal view
- `src/components/OrderTrackingCard.jsx` — order delivery tracking card
